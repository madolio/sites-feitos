# NBJ Systems

Landing page da NBJ Systems — equipamentos para filtração e purificação de água.

Vite + React + TypeScript + Tailwind CSS.

Conteúdo baseado no site original da empresa (nbjtratamentodeagua.com.br), redesenhado do zero.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
